# 面试助手 · 安装包下载

面试助手是一款面试陪练工具：AI 面试官结合你的简历和目标岗位出题，用语音提问并点评你的回答；也能在线上面试时实时识别面试官的问题，给出参考回答。

## 下载

到 [Releases](../../releases/latest) 下载最新版本：

| 系统 | 下载哪个文件 |
| --- | --- |
| Windows 10 / 11（64 位） | `InterviewCopilot_x.y.z_x64-setup.exe` |
| macOS 14 及以上（Apple 芯片：M1 / M2 / M3 / M4） | `InterviewCopilot_x.y.z_aarch64.dmg` |

`.exe` 只能在 Windows 上用，`.dmg` 只能在 Mac 上用。暂不支持 Intel 芯片的 Mac（可在「关于本机」里查看芯片）。

装好之后不用再来这里，有新版本时打开面试助手会自动提示更新。

## Windows：安装时提示「Windows 已保护你的电脑」

内测版本暂未做代码签名，Windows 会弹出这个提示。点「更多信息」→「仍要运行」即可继续安装，不需要管理员权限。

## Mac：第一次打开

1. 双击 `.dmg`，把「面试助手」拖进「应用程序」文件夹。
2. 在「应用程序」里打开面试助手。内测版本暂未经过苹果公证，会提示「无法验证开发者」，点「完成」关掉。
3. 打开「系统设置 → 隐私与安全性」，拉到下方，在面试助手旁边点「仍要打开」，输入开机密码确认。之后就能正常打开了。
4. 第一次用到时会请求两个权限，都要点「允许」：
   - **麦克风**：模拟面试时录你的回答；
   - **系统录音**（「录制屏幕与系统录音」中的「仅录制音频」）：线上面试时听到面试官的声音。需要 macOS 14.2 及以上。

如果之前点了「不允许」，可以到「系统设置 → 隐私与安全性 → 麦克风 / 录制屏幕与系统录音」里重新打开。

## 系统要求

- Windows 10 / 11（64 位），或 macOS 14 及以上的 Apple 芯片 Mac（实时识别面试官需要 macOS 14.2+）
- 需要联网使用
